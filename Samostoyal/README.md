# Новая самостоятельная 21 сентября 2026 после выборов в гос. думу

## 📚 Описание
Репозиторий содержит набор Bash-скриптов, выполненных в рамках самостоятельной работы.

## 📂 Структура

| Файл | Описание |
|------|----------|
| `Sam.sh` | Приветствие по имени пользователя |
| `SamMath.sh` | Калькулятор суммы двух чисел |
| `ChetNechet.sh` | Проверка чётности числа |
| `SetProject.sh` | Создание структуры веб-проекта |
| `Shetchik.sh` | Счётчик строк в файле |
| `Passwords.sh` | Генератор пароля (8 символов) |
| `Seeker.sh` | Поиск файлов по расширению |
| `Stats.sh` | Анализ репозитория GitHub |
