### управление консолью (Bash)

сдвинуть лог вверх
`Ctrl+L`

Очистить экран
`clear`

получить историю
```
                                         history
```

перелистование ранее введённых команд
`up/dowm` (стрелки)

выполнить последнюю команду из списка history
```
!!
```

выполнить указанную команду из списка history
```
!45
```
где 45 это порядковый номер команды из history

остановить запущенный процесс через `Ctrl+C`

### файловые операции

получить структуру каталогов и файлов
```
tree
```
получить абсолютный путь к текущему каталогу
```
pwd
```
показать содержимое текущего каталога
```
ls
```
или подробно
```
ll
```
или
```
ls -all
```
показать содержимое указанной папки
```
ls Dir_name
```
где `dir_name` это имя указанной или нужной папки

Правила именования каталогов и файлов
1. только по английски
1. без пробелов и спец. символов
1. если имя файла или каталога состоит из нескольких английских слов, то имя можно создать так:
`firstOfall` или `first_of_all`
1. в имени файлов лучше всегда указывать расширение `FileName.txt` и т.п.

Выйти из текущей папки
```
cd ..
```
Вернуться в предыдущую папку
```
cd -
```
Зайти в указанную папку
```
cd TargetFolder
```
Знаки:
`\` обратный слэш - признак каталога
`/` прямой слэш - признак каталога
`|` вертикальный слэщ - признак разделения команд

Windows

`\` - корневой каталог
Unix/Linux/Android/macOS/IOS/BSD/SteamOS
`/` - корневой каталог

выйти из текущего каталога на 2 шага вверх (древу)
```
cd ../..
```
### Создание файлов и каталогов

Создание файлов
```
touch file_name.txt
```
Редактировать текстовый файл
```
micro File_name.txt
```
- micro - текстовый редактор командной строки
- Сохранить по `Ctrl+S` и выйти из редактора по `Ctrl+Q`

копирование файла
```
cp namefile.txt newfolder/
```
переместить файл
```
mv file.txt TargetName
```
удалить файл
```
rm file.txt
```
удалить папку
```
rm -rf Folder
```
создать несколько файлов
```
touch {1..4}
```
создать несколько каталогов
```
mkdir foldername{1..4}
```
удалить содержимое текущего каталога
```
rm -rf *
```
создать структуру поректа:
```
project/
├── css/
├── js/
├── img/
│   └── ico/
├── fonts/
└── pages/
```
создать такую структуру можно одной командой
```
mkdir -p project/{css,js,img/ico,fonts,pages}
```
