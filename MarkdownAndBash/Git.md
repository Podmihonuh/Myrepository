## Основы Git (Guten Tag)

#### Почему не флешка?

1. флешка - потенциальный разносчик вирусов
1. Ваши личные данные могут случайно попасть на чужой компьютер
1. Антивирус может удалить ваши файлы с флешки
1. Флешка может поетряться или сломаться

#### почему не Яндекс или Google диск?
1. Облако яндекс или гугл не контролирует версии файла
1. Ваши данные к яндекс или гугл могут случайно остаться на чужом компьютере

### преимущества Git

1. Трудно потерять свои проекты
1. Легко отслеживать версии ваших проектов
1. Легко делиться с другими людьми вашими проектами
1. Легко вести совместную работу над одним проектом
1. Git - Де-факто стандарт в IT и интегрирован почти во все современные технологии IT (например VS Code etc.)
1. в Git можно создавать веб-страницы как на хостинге
1. Git-сервисы дают возможность автоматизировать сборки и тестирование ваших приложений

### основные состояния git-репозитория

1. **Инициализация** - `git status` - показывает текущее состояние репозитория
1. **Подготовка** - `git add .` - подготовка (добавление) изменений
1. **Фиксация** - `git commit -m "message"`
1. **синхронизаця** с удалённой копией текущего репозитория

### Что можно сохранять в Git?

1. любые текстовые файлы объёмом <= ~40 Mb.
1. Изображения, документы, mp3, PDF, gif, и т.п.
1. все имена файлов и каталогов только по английски, без пробелов и спец. символов.

### Основные команды Git

Получить версию установленного Git:
```shell
git version
```
или
```shell
git --version
```
Получить справку
```shell
git help
```
**сменить редактор по умолчанию**
На `Micro` (проще для новичков)
```shell
git config --global core.editor "micro"
```
На `Nano` (чуть сложней для новичков)
```shell
git config --global core.editor "nano"
```
На `VS Code` (элементарен для новичков)
```shell
git config --global core.editor "code --wait"
```

**представиться системе Git**
Сообщить свой никнейм
```shell
git config --global username "Kakashka"
```
Сообщить свой имейл
```shell
git config --global user.email "my_email@gmail.com"
```
**Если вы на чужом компе то вместо `--global` используйте `--local`**

#### Клонирование репозитория

```shell
git clone "address"
```
Открыть папку клонированного репозитория
```shell
cd foldername
```
Получить статус текузего репозитория
```shell
git status
```
Получить состояние удалённого репозитория
```shell
git remote show origin
```
Получить локальные ветки текузего репозитория
```shell
git branch
```
Получить список удалённых веток
```shell
git remote --v
```
получить общий лог
```shell
git log
```
получить лог изменений с указанием кол-ва последних коммитов
```shell
git log -p
```
Выйти из логов по клавише `q`
